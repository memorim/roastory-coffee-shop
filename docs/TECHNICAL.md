# Roastory — интернет-магазин кофе

Fullstack-магазин свежеобжаренного specialty coffee с каталогом, фильтрами, корзиной и оформлением заказа.

## Возможности

- каталог и фильтрация по способу обработки;
- корзина с сохранением в `localStorage`;
- серверный пересчёт стоимости заказа;
- транзакционное сохранение заказа и позиций;
- SQLite, валидация Zod и API-тесты;
- адаптивная коммерческая витрина.

## Запуск

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4500`. На Windows доступен `start-local.cmd`.

```bash
pnpm test
```

## Текущий режим работы
Заказ и позиции сохраняются в одной BEGIN IMMEDIATE транзакции вместе с чтением серверных цен. Дубли SKU отклоняются. Повтор Idempotency-Key возвращает исходный заказ; изменение данных с тем же ключом даёт 409. Ключ формы хранится в памяти вкладки, после перезагрузки это новая операция. Контакты не возвращаются через просмотр заказа. Оплата, доставка и почтовые уведомления не подключены. Локальный API не имеет аккаунтов, не предназначен для внешнего сбора контактов и требует резервного копирования SQLite.
