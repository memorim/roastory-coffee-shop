# Roastory — интернет-магазин кофе

Fullstack-магазин свежеобжаренного specialty coffee с каталогом, фильтрами, корзиной и оформлением заказа.

## Возможности

- каталог и фильтрация по способу обработки;
- корзина с сохранением в `localStorage`;
- серверный пересчёт стоимости заказа;
- транзакционное сохранение заказа и позиций;
- SQLite, валидация Zod и API-тесты;
- адаптивная коммерческая витрина.

## Запуск

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4500`. На Windows доступен `start-local.cmd`.

```bash
pnpm test
```
