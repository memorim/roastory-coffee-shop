# Roastory — интернет-магазин кофе

Показывает каталог кофе и сценарий оформления заказа.

**Тип:** Самостоятельный портфолио-проект. Рабочая демонстрационная реализация; коммерческий запуск и использование реальными пользователями не заявляются.

## Что работает
- Каталог и фильтры по обработке кофе.
- Корзина в localStorage, отправка и сохранение демонстрационного заказа.
- Серверный пересчёт суммы, транзакционная запись заказа и позиций.

## Стек
JavaScript, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- Стоимость заказа берётся из серверного каталога.
- Корзина хранит товары независимо от активного фильтра каталога.

## Границы готовности
- Платёжная система, доставка, письма и личный кабинет не подключены.
- Товары, оценки и описания — демонстрационные.
- Нет production-авторизации и контроля доступа к заказам. Использовать только с вымышленными данными.
